# Astra — голосовой ИИ-ассистент (Android)

Скелет Android-проекта: Kotlin + Jetpack Compose + Hilt + Room + DataStore.
`minSdk = 29` (Android 10), `targetSdk = 34`, `compileSdk = 34`.

## ✨ Что добавлено в этой версии: "не выключается" + красивее интерфейс

**Устойчивость службы (чтобы ассистент не выключался сам):**
- **Исправлен реальный баг** — раньше разрешение на микрофон нигде не запрашивалось в рантайме, и голосовые функции просто не могли бы заработать. Теперь `MainActivity` сама спрашивает `RECORD_AUDIO`/уведомления при первом запуске.
- Добавлен запрос на исключение из оптимизации батареи (`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`) — главная причина, по которой Android/MIUI/EMUI сами "убивают" фоновые службы через какое-то время.
- `AssistantForegroundService.onTaskRemoved()` — если пользователь смахнёт приложение из списка недавних, служба сама перезапускается через `AlarmManager` вместо того, чтобы просто исчезнуть (стандартное поведение Android без этого переопределения).
- `AssistantForegroundService.onDestroy()` — на случай, если систему всё же прибьёт службу (крайняя нехватка памяти), она пытается подняться заново.
- `START_STICKY` (было и раньше) — система пересоздаёт службу после нехватки памяти.

**Важно быть честным:** "никогда не выключается" на 100% гарантировать невозможно ни одному Android-приложению — у системы всегда есть право принудительно остановить любой процесс при критической нехватке ресурсов, а часть производителей (особенно китайские прошивки) агрессивно душат фон вне зависимости от кода. Но с этими изменениями служба переживёт: закрытие приложения свайпом, обычную оптимизацию батареи и мелкие сбои — то есть кардинально надёжнее, чем было.

**Интерфейс:**
- Добавлен `StarryBackground` — лёгкий слой мерцающих звёзд поверх градиента (одна анимация на весь набор точек, не нагружает производительность).
- `AnimatedOrb` переработан — теперь два слоя: мягкое внешнее свечение + плотное ядро с градиентом (было — одна плоская заливка).
- `GlassCard` — добавлена мягкая тень, карточки теперь визуально "парят" над фоном, а не просто плоские прямоугольники.

## 🔑 Куда вставить ключ LLM API
1. В корне проекта (рядом с `settings.gradle.kts`) открой (или создай, если Android Studio его ещё не создала) файл **`local.properties`** — это обычный текстовый файл, НЕ .kt и не в git.
2. Допиши в него строку:
   ```
   LLM_API_KEY=твой_настоящий_ключ_сюда
   ```
   (пример полностью — в `local.properties.example`, скопируй из него структуру).
3. Всё — больше ничего трогать не нужно. `app/build.gradle.kts` сам подхватит ключ из `local.properties` и положит его в `BuildConfig.LLM_API_KEY`, а `di/AppModule.kt` сам передаст его в `LlmApiClient` при старте приложения.
4. После правки `local.properties` сделай **File → Sync Project with Gradle Files** в Android Studio, чтобы `BuildConfig` пересобрался с новым значением.

Почему не прямо в коде: `local.properties` уже в `.gitignore`, поэтому ключ не попадёт в git/GitHub, если ты в будущем запушишь проект. Если вписать ключ прямо в `.kt`-файл — он останется в истории репозитория даже после удаления.

## 🚀 Как собрать .apk без Android Studio (через GitHub Actions)

Если Android Studio не может скачать нужные файлы (проблемы с сетью/антивирусом), можно собрать `.apk` прямо на серверах GitHub — у них интернет всегда работает, тебе не нужно ничего устанавливать локально вообще.

### Шаг 1. Создай аккаунт на GitHub
Зайди на **github.com**, зарегистрируйся (если ещё нет аккаунта). Это бесплатно.

### Шаг 2. Создай новый репозиторий
1. Нажми **+** в правом верхнем углу → **New repository**.
2. Название — например `astra-assistant` (любое).
3. Оставь **Public** или **Private** — не важно, оба варианта дают бесплатные Actions.
4. **НЕ** ставь галочку "Add a README file" — у нас он уже есть в проекте.
5. Нажми **Create repository**.

### Шаг 3. Загрузи туда файлы проекта (без установки git на компьютер)
1. На странице пустого репозитория будет ссылка **"uploading an existing file"** — нажми её.
2. Распакуй скачанный zip у себя на компьютере (если ещё не распаковал).
3. Открой папку `astra-assistant` (там, где `build.gradle.kts`), выдели ВСЁ её содержимое (Ctrl+A) и перетащи прямо в окно браузера на странице GitHub (drag & drop).
   - Важно: закидывать нужно **содержимое** папки `astra-assistant`, а не саму папку `astra-assistant` как один элемент — иначе структура папок в репозитории будет на уровень глубже, чем нужно.
4. Внизу страницы нажми **Commit changes**.

### Шаг 4. Добавь свой API-ключ как секрет (не в файл!)
1. В репозитории: **Settings** (вкладка сверху) → слева **Secrets and variables → Actions**.
2. Нажми **New repository secret**.
3. Name: `LLM_API_KEY`
4. Secret: вставь свой настоящий ключ.
5. **Add secret**.

### Шаг 5. Запусти сборку
1. Перейди на вкладку **Actions** (сверху репозитория).
2. Слева должен появиться workflow **"Build APK"** — нажми на него.
3. Справа нажми кнопку **Run workflow** → **Run workflow** (зелёная кнопка в выпадающем меню).
4. Подожди 2-5 минут, пока идёт сборка (жёлтый кружок → зелёная галочка = успех).

### Шаг 6. Скачай готовый .apk
1. Кликни на завершившийся запуск (с зелёной галочкой) в списке Actions.
2. Внизу страницы будет раздел **Artifacts** → файл `astra-assistant-debug-apk` — нажми, чтобы скачать (придёт как zip, внутри — `app-debug.apk`).
3. Перекинь `app-debug.apk` на телефон (через USB, Telegram самому себе, Google Drive — как угодно) и открой файл на телефоне, чтобы установить.
   - Android спросит разрешение на установку "из неизвестных источников" — подтверди для конкретно этого файла.

Если на каком-то из шагов Actions покажет ошибку (красный крестик) — открой этот запуск, разверни шаг с ошибкой и пришли мне текст ошибки, разберём.

## Что уже готово
- Структура проекта, Gradle-конфигурация, зависимости. **~1730 строк Kotlin-кода.**
- Manifest с нужными разрешениями (микрофон, foreground service, автозапуск после загрузки).
- `BootReceiver` + `AssistantForegroundService` — автозапуск и фоновая работа.
- Тема **glassmorphism** (градиентный фон, `GlassCard`, анимированный `AnimatedOrb`).
- 4 экрана с нижней навигацией: Главная (орб), Чат, **Команды** (список + форма добавления), Настройки (имя/голос/язык).
- Полноценный **ViewModel-слой** (Hilt): `HomeViewModel`, `ChatViewModel`, `SettingsViewModel`, `CommandsViewModel` — экраны больше не используют локальный `remember`-стейт, а читают/пишут через репозитории.
- `SpeechRecognizerManager` (STT) и `TextToSpeechManager` (TTS с подбором голоса по полу/языку).
- `IntentMatcher` — локальный fuzzy-матчер команд (Левенштейн), офлайн, без LLM.
- `CommandsRepository` — обёртка над Room с сидированием встроенных команд (`BuiltInCommands`: YouTube, камера, настройки, поиск, погода, карты, почта, "как тебя зовут") и матчингом голосовой фразы.
- `LlmApiClient` — тонкий HTTP-клиент к LLM API (Anthropic Claude API) на `HttpURLConnection`, без сторонних зависимостей.
- `LlmRepository` — чат с сохранением истории в Room (`ChatMessageEntity`/`ChatMessageDao`) + **fallback-разбор нечёткой речи**: если STT выдал низкую уверенность и локальный матчер не нашёл команду, `HomeViewModel` обращается к LLM, чтобы восстановить вероятный смысл фразы.
- Реальное **выполнение команд** в `NavGraph.executeCommand()`: открытие приложения по package name, открытие URL, запуск системного intent action, произнесение текста — с обработкой `ActivityNotFoundException`.
- `PermissionsHelper` — список нужных runtime-разрешений и пояснения к ним для UI.
- `SettingsDataStore` — хранение имени ассистента, пола голоса, языка.
- Локализация: `values` (ru, по умолчанию), `values-en`, `values-be`, `values-es`.

## Что нужно доделать (пометено `// TODO` в коде)
1. **API-ключ для LLM** — сейчас `LlmApiClient.apiKey` пустой; для продакшена ключ нельзя хранить в клиенте открытым текстом — нужен backend-прокси (например, свой сервер, который проксирует запросы к LLM API и хранит ключ на сервере).
2. **Backdrop-blur под GlassCard** — сейчас карточка полупрозрачная без размытия фона под ней; для настоящего blur-эффекта на API 31+ можно использовать `RenderEffect`, либо подключить библиотеку `dev.chrisbanes.haze:haze`.
3. **Wake word "Astra"** без нажатия кнопки — интеграция Porcupine (Picovoice) или Vosk, чтобы ассистент активировался по имени в фоне (сейчас запуск прослушивания — по кнопке микрофона).
4. **Экран запроса разрешений** — `PermissionsHelper` уже определяет список и пояснения, но UI-флоу запроса (диалог/экран онбординга) ещё не подключён к `MainActivity`.
5. **Реальные launcher-иконки** — сейчас используется простая векторная заглушка `ic_astra_orb.xml`.
6. Обработка ограничений автозапуска на MIUI/EMUI/др. — экран-инструкция для пользователя.
7. Редактирование существующих команд (сейчас в `CommandsScreen` можно добавлять и удалять, но не редактировать — метод `CommandsRepository.updateCommand` уже есть, не хватает UI).

### Полное ТЗ

Роль: senior Android-разработчик (Kotlin, Jetpack Compose), делающий голосового ИИ-ассистента.

Ключевые требования:
- Имя по умолчанию — **Astra**, с возможностью переименования и выбора голоса (муж/жен) в настройках.
- Голосовые команды: встроенные ("открой YouTube" и т.п.) + пользовательский конструктор команд (триггер-фраза → действие: открыть приложение/URL/системный intent/произнести текст).
- Обратная связь: при распознавании команды — сразу "Выполняю", после завершения — "Выполнено"; при непонятной фразе — переспрос, а не ошибка.
- Понимание нечёткой речи: STT с уверенностью → при низкой уверенности отправлять текст на LLM для коррекции и разбора смысла.
- Полноценный чат-режим с ИИ (история, стриминг, markdown).
- Автозапуск сразу после включения устройства (`BOOT_COMPLETED` + foreground service).
- Дизайн: **glassmorphism** — полупрозрачные карточки с blur, тонкая обводка, тёмный космический градиентный фон, анимированный орб-индикатор состояния (ожидание/слушаю/думаю/говорю).
- Мультиязычность ответов: русский, английский, белорусский, испанский — выбирается в настройках отдельно от системного языка.

Смотри код проекта — он уже реализует базовую архитектуру под все пункты выше; используй существующие классы (`SpeechRecognizerManager`, `TextToSpeechManager`, `IntentMatcher`, `SettingsDataStore`, `CommandDao`, компоненты в `ui/`) как основу и не создавай дублирующую логику.
